# Glossary: English → Bahasa Melayu (Bible content)

A real profile builds this up script by script: when a key term comes up that isn't here, the agent proposes an entry instead of picking one silently, and the reviewer approves it.

| English | Bahasa Melayu | Notes |
|---|---|---|
| Psalm, Psalms | Mazmur | Book name as in the Alkitab Versi Borneo (AVB) |
| King James Version | Alkitab Versi Borneo | A version label is replaced by the version actually quoted |
| blessed (is the man) | diberkatilah | AVB wording |
| the righteous | orang benar | AVB wording |
| the ungodly, the wicked | orang zalim | AVB wording |
| account | akaun | Not *akun* (Indonesian) |
| settings | tetapan | Not *pengaturan* (Indonesian) |
| car | kereta | Not *mobil* (Indonesian) |
| telephone | telefon | Not *telepon* (Indonesian) |
