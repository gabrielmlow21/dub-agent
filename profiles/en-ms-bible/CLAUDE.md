# Instructions for Claude (English → Malaysian Malay, Bible content)

This profile was used for the Psalm 1 demo. A real client's profile has the same files with its own rules, and stays private.

To dub a script, use the `dub` skill with this folder as the profile. The rules below are this client's; they win over the skill's defaults.

## Translating
- Follow `style-guide.md` and use the terms in `glossary.md`.
- Use Malaysian Malay, never Indonesian spellings or vocabulary.
- Quote verses word for word from the Alkitab Versi Borneo (AVB); don't translate them yourself.
- A version label read aloud ("King James Version") becomes "Alkitab Versi Borneo".

## Voice text
- One verse per block.
- Keep spoken headings ("Mazmur 1."), since the original reads them aloud.
